# SWYNEX – Exploratory Data Analysis

## Task 2: Exploratory Data Analysis (EDA)

This project was completed as part of the **SWYNEX Technologies Data Analyst Internship**.

## Project Overview

The objective of this project is to perform Exploratory Data Analysis (EDA) on the Student Performance dataset to understand student performance patterns across Mathematics, Reading, and Writing.

## Dataset

- Dataset: Student Performance in Exams
- Total Records: 1,000
- Total Columns: 8
- Missing Values: 0
- Duplicate Records: 0

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Analysis Performed

1. Overall Average Scores Analysis
2. Gender-wise Student Performance
3. Test Preparation Course Analysis
4. Lunch Type vs Student Performance
5. Parental Education vs Student Performance

## Key Insights

1. **Overall Performance:** Reading had the highest average score (69.17), followed by Writing (68.05) and Mathematics (66.09).
2. **Gender Differences:** Female students scored higher on average in Reading and Writing, while male students scored higher in Mathematics.
3. **Test Preparation:** Students who completed the test preparation course had higher average scores across all three subjects.
4. **Lunch Type:** Students receiving standard lunch had higher average scores than students receiving free/reduced lunch.
5. **Mathematics Performance:** Mathematics had the lowest overall average score. Students receiving standard lunch scored 11.11 points higher in Mathematics on average than those receiving free/reduced lunch.

These findings describe associations in the dataset and do not establish causation.
